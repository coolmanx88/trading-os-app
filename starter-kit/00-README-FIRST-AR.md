# Trading OS Starter — ابدأ من هنا

هذه الحزمة تنشئ نسخة مستقلة من Trading OS على حساب GitHub جديد.

## ترتيب التنفيذ

1. اقرأ `03-GitHub-Setup-AR.md`.
2. أنشئ المستودعين المطلوبين:
   - `trading-os-app` — Public
   - `trading-os-data` — Private
3. ارفع محتويات `01-trading-os-app` إلى المستودع العام.
4. ارفع محتويات `02-trading-os-data` إلى المستودع الخاص.
5. أنشئ Fine-grained Personal Access Token حسب الخطوات في الدليل.
6. فعّل GitHub Pages للمستودع العام باستخدام GitHub Actions.
7. افتح Trading OS واربطه بالمستودع الخاص.
8. اختبر Sync.
9. بعد نجاح كل ما سبق، أعطِ ChatGPT الملف `04-ChatGPT-Prompt-AR.md` أو انسخ محتواه في المحادثة.
10. نفّذ `05-Checklist-AR.md` قبل بدء الاستخدام الحقيقي.

## الأمان

- لا تحتوي الحزمة على بيانات تداول المستخدم الأصلي.
- لا تحتوي على GitHub Token.
- لا ترسل Token إلى ChatGPT.
- يجب أن يبقى `trading-os-data` Private.
